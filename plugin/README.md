# DSH 身份验证

非官方实验项目。普通插件安装只提供合成演示，不触发系统认证。
在 DSH 内发起一次 macOS 系统验证。系统负责指纹和密码，插件只接收本次结果。
当前原生入口需要本仓库的独立实验桌面适配层，适配目标为 DSH `0.2.2-rc.3`。
点击「验证身份」，在原生窗口核对自检用途后，亲自完成系统验证。
这次自检的结果绑定调用窗口、调用方、动作、策略和期限，只返回一次。
当前不提供会话加密、锁定或解封。这些操作由接入验证器的调用方管理。
取消、超时或失联均结束本次请求，结果未确认时会明确提示。
普通 Web 环境只保留合成演示。社区分发与其他插件接入仍待各自验收。
