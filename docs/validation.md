# 当前验证范围

记录日期 2026-11-17，原生实验目标为 DSH `0.2.2-rc.3`、Electron `44.7.0`、macOS `27.2`、Apple Silicon。源码预发行版本 `0.1.0-m3.1` 增加公开元数据与许可，认证核心沿用 M3 实验实现。

| 层次 | 已有证据 | 尚未证明 |
| --- | --- | --- |
| 普通插件 | 实际 DSH Host/Client 合成往返、一次消费、取消与停用回归 | 真实系统认证、业务访问控制 |
| 原生来源 | 独立主窗口/主框架登记、来源守卫、标准 Renderer 设置、私有 fd4 通道就绪 | 普通发行版无需适配层接入 |
| 本人操作 | 一次 `system-owner` / `demo_verify` / `granted` 回执 | 具体认证机制、系统面板取消、焦点恢复、全部实机事件 |
| helper | arm64/x86_64 构建 slice、本机 ad-hoc 签名、无弹窗预检 | Intel 真机、签名公证、干净 Mac 安装卸载回退 |
| 后续数据保护 | 已规划会话保护与恢复验收 | 会话加密、锁定、解封、毛玻璃隐私界面 |

已准备的本机运行时中曾有 52 项相关 Node 回归通过、零跳过；纯参数、错误映射与 helper 无弹窗检查通过。公开源码不携带 `.lab`，三个上游 Connection 集成用例将跳过，结果必须分别报告。

当前包没有原生 helper 二进制，也不自动修改桌面应用。尚未完成面向普通用户的原生安装路径，请按实验源码评估。
